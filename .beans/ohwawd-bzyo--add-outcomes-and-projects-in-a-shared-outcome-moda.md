In the outcome catalog, replace the expandable accordion-style outcome creation flow with the same overlay modal pattern used when adding projects to an outcome. Allow users to create the outcome and add projects to it in the same modal workflow.

Acceptance criteria:
- Starting outcome creation opens an overlay modal consistent with the existing add-project overlay.
- The modal supports entering the new outcome and selecting/adding projects to that outcome before submitting.
- The workflow does not require a separate follow-up flow to attach projects.
- Existing behavior for adding projects to an already-existing outcome remains available.
